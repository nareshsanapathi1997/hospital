# hospital

Aurelia Multispeciality Hospital demo. Start it with `npm install` and `npm run dev`, then open [http://localhost:5173/](http://localhost:5173/).

## Demo links

- [Patient dashboard](http://localhost:5173/patient-portal) — appointments, reports, and the logged-in patient preview
- [Admin dashboard](http://localhost:5173/about?portal=admin#portals) — hospital admin preview (beds, staff, and department performance)
- [Dashboards](http://localhost:5173/about#portals) — patient, doctor, and admin previews on one screen
